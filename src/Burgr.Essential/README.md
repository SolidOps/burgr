# Burgr.Essential

The default model parser (YAML) and the default generators of [burgr](https://github.com/SolidOps/burgr), the deterministic, model-driven code generator.

Any template set can use these building blocks as they are, or replace them through `burgr.json`. Built on [`Burgr.Core`](https://www.nuget.org/packages/Burgr.Core).

To generate code, install the tool:

```sh
dotnet tool install --global Burgr
```

Documentation: <https://github.com/SolidOps/burgr#readme>
