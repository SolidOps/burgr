# Burgr.Core

Core abstractions of [burgr](https://github.com/SolidOps/burgr), the deterministic, model-driven code generator.

Reference this package to write your own model parser, template engine or code generator, loaded through `ModelParserEngineType`, `TemplateParserEngineType` and `Generators` in `burgr.json`.

If you only want to generate code, install the tool instead:

```sh
dotnet tool install --global Burgr
```

Documentation: <https://github.com/SolidOps/burgr#readme>
